# Kama Morton personal website

This is a minimalist academic-style personal website inspired by the clean whitespace template from Jonas Frey, adapted for Kama Morton's resume and professional profile.

## Run locally

From the project folder, start a web server:

```bash
cd "/Users/kamamorton/Desktop/NET IMPACT/Personal_Website_Kama"
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Files

- `index.html` – one-page portfolio structure
- `style.css` – custom styling and layout
- `Kama Morton - Resume.pdf` – resume preview embedded on the right side of the page
